기본 제공 기능

로그인 후 첫 화면부터 권한별 메뉴, 공통코드까지 — 구축 프로젝트마다 다시 만들던 것들이 처음부터 들어 있습니다.

대시보드

경영 현황 KPI와 추이 차트를 역할별로 자동 구성. Recharts 기반 실시간 차트, 한국어·영어 지원.

회원사 · 사용자 관리

멀티테넌트 구조로 회사별 독립 데이터 공간. 회원사 등록·승인·정지 워크플로우, 사용자 계정 일괄 관리, 이력 보존.

역할 · 권한

역할 단위로 메뉴·기능별 조회·수정·삭제 권한을 설정. 사용자-역할 다대다, 솔루션 단위 역할 분리, JWT 기반 인증.

메뉴 관리

트리 구조 메뉴를 DB에서 동적으로 로드. 배포 없이 추가·수정·순서 변경, 역할별 노출 메뉴 자동 필터, 다국어 메뉴명.

공통코드 · 채번

전사 공통 코드와 자동 채번 규칙(접두어·년월일·자릿수·리셋 주기)을 중앙에서 관리. 변경 즉시 전체 시스템 반영.

시스템 환경설정

암호화 정책, 업무 필드 커스터마이징, 시스템 메시지 관리.

멀티테넌트 구조

하나의 설치로 여러 회사가 독립된 데이터 공간을 씁니다. 회원사 코드는 채번 서비스가 자동 생성하고, 모든 테이블은 사업장·회원사 키와 표준 감사(Audit) 컬럼을 가집니다. 삭제는 Soft Delete로 처리해 이력이 남습니다.

  • 사업장(house) · 회원사(company) 2단계 테넌트 키
  • 등록·수정 사용자와 시각을 기록하는 표준 감사 컬럼
  • 역할별 데이터 자동 필터링

NF1 위에 올라가는 제품

Manager, ERD, PM, Logistics는 모두 NF1의 회원·권한·메뉴 체계를 그대로 씁니다. 한 번 로그인하면 권한이 있는 제품 메뉴가 함께 보입니다.
