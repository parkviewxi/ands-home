홈/사업영역

컨설팅에서 구축, 운영까지
시스템 생명주기 전체를 맡습니다

정보화 마스터플랜 수립, 시스템 설계·개발, 항공화물·물류 도메인 솔루션, 그리고 구축 이후의 유지보수까지 다섯 영역에서 일합니다.

정보화 컨설팅 · ISMP

현행 시스템의 문제를 정확히 진단하고, 바로 발주할 수 있는 수준의 마스터플랜과 제안요청서(RFP)를 만듭니다.

  • 현행 환경 분석: 운영 현황, 문제점, 인프라(서버·네트워크·보안·DB) 진단과 현장 조사
  • 목표 모델 설계: 웹 3-Tier 전환, 통합 DB, OpenAPI·EAI 표준 연계, 클라우드·온프레미스 배치 모델
  • 이행계획: 단계별 로드맵, TTA 지침 기반 하드웨어 규모산정, 기능점수(FP) 기반 소프트웨어 대가산정
  • RFP 패키지: 기능·비기능 요건기술서, 소요예산 산출근거, 분리발주 대상 분류, 제안요청·평가 기준(안)

최근 수행 한국관세무역개발원 화물관리시스템 전면 재구축을 위한 ISMP 용역(2026), 북마케도니아·자메이카 관세행정 BPR/ISP 컨설팅(2020)

4단계 표준 컨설팅 수행 프레임워크

검증된 공학적 컨설팅 기법을 발주기관 현황에 맞춰 적용합니다. 단계마다 산출물을 정의하고 발주기관과 합의해 추적성을 보장합니다.

  1. 착수 · 환경분석

    내부 거버넌스 정립, 대내외 비즈니스 분석, 선진 기술 아키텍처 벤치마킹

  2. As-Is 진단

    현장 전수 분석, 업무 프로세스 갭(Gap)과 데이터 이원화 병목 규명

  3. To-Be 설계

    웹 3-Tier 아키텍처와 단일 통합 DB 스키마 설계, OpenAPI 연계 방안 수립

  4. 이행계획 · RFP

    기능점수 기반 개발비 산정, 조달 발주 가능한 제안요청서 완벽 제정

시스템 구축(SI)

기획·분석·설계·개발·시험·운영 전 과정을 수행합니다. 오픈소스 기반 엔터프라이즈급 시스템으로 고객의 기술 부채를 줄이는 아키텍처를 지향합니다.

  • 웹 표준 3-Tier(WEB-WAS-DB) 아키텍처, 무설치 중앙배포
  • SQX 프레임워크 기반 구축 — Next.js·React·Vue·Spring Boot·FastAPI 중 고객 인프라에 맞는 스택 선택
  • 행정기관·공공기관 정보시스템 구축·운영 지침에 따른 소프트웨어 개발보안 적용과 보안 취약점 진단
  • 단위·통합·시스템통합·인수시험, 성능 KPI 검증, 시험운영과 안정화, 교육·기술이전

최근 수행 광양 산업단지 스마트물류플랫폼 기획·설계·개발(2024~2025), 물류관리 모바일 플랫폼 개발(2026)

항공화물 터미널 · 통관 시스템

공항 화물터미널의 수출·수입·환적 업무와 관세청·항공사·조업사 사이의 전자문서 흐름을 2011년부터 직접 설계·구축해 왔습니다. 터미널 운영시스템과 그 바깥의 연계까지 한 손에 맡길 수 있는 범위입니다.

  • 터미널 운영시스템(CMS): 반입·장치·보관·반출, 빌드업(Build-up)·브레이크다운(Breakdown), 보류·세화 관리, 보관료 정산, 기준정보·권한 관리
  • 전자문서 연계: 관세청 UNIPASS 적하목록·반입/반출 신고, 항공사 FSU/FFM 메시지, 조업사 적하목록 취합, 포워더 AWB 사전정보
  • 특송·보세구역 화물관리: 특송센터와 지정장치장 화물관리시스템 진단과 재구축 설계
  • 통합 관제·모니터링: 설비·이동체 상태와 화물 흐름을 한 화면에 모으는 웹 기반 관제 화면, KPI 대시보드, PDA·모바일 현장 서비스
  • 구축 이후: 시험운영과 성능 검증, 운영자 교육, 기술이전, 유지관리

수행 근거 적하목록 전자문서 중계 시스템 구축(2011~2012), 관세청 4세대 유니패스 화물시스템 분석·설계(2013~2016), 한국공항(KAS) 적하목록 취합시스템 구축(2014~2015), 전자상거래 수출신고 플랫폼 구축(2015~2016), 항공 AWB 취합·중계 구축, 화물관리시스템 전면 재구축 ISMP(2026)

물류 · 항만 솔루션

포워딩·창고·운송·선적검수를 하나로 묶은 SQX Logistics와, 항만 운영 현장을 위한 플랫폼으로 물류 현장을 디지털화합니다.

  • SQX Logistics: FMS(포워딩) · WMS(창고) · TMS(운송) · ATS(선적검수) — 클라우드 SaaS 또는 고객 인프라 설치형
  • 창고 로케이션 3D 뷰, 바코드·QR 기반 입출고, 모바일 현장 처리
  • 항만 물류서비스: 선석·선박 현황, 화물 적재(stowage), 작업 지시를 통합한 항만 운영 플랫폼
  • 스마트팩토리 연계: 생산 현장의 MES·ERP·SCM과 물류 데이터를 잇는 디지털화·자동화 설계

수행 근거 종합물류 통합시스템(FMS·TMS·WMS) 구축, 광양 산업단지 스마트물류플랫폼(2024~2025), SQX Logistics 자체 개발

IT 서비스 유지 · 보수

시스템은 구축한 뒤가 더 깁니다. 장애 대응, 예방 정비, 서비스 수준 관리로 운영의 연속성을 지킵니다.

  • 신속한 장애 대응: 24시간 모니터링과 장애 접수 체계, 원인 분석과 재발 방지
  • 체계적인 관리: 정기 점검과 예방 정비, 버전 관리와 변경 이력 관리
  • 맞춤형 SLA: 고객 업무 특성에 맞는 가동률·복구시간 목표와 보고 체계
  • SQX Manager로 컨테이너·서버·DB·API·로그를 한 콘솔에서 관찰하고, SQX PM의 ITSM으로 요청·장애·변경을 관리
