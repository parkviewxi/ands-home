네 가지 모듈

모듈은 따로 도입할 수 있지만 같은 화주·화물·위치 기준정보를 공유합니다. 포워딩에서 접수한 화물이 창고 입고, 운송 배차, 선적 검수로 그대로 이어집니다.

FMS — 포워딩

수출입 주문 접수부터 BL·HBL·MBL 발행, 컨테이너 배정과 적재 계획(CLP), 선적 확정, 도착지 서류까지. 선박 위치 추적, 운임 산출과 청구서 자동 생성.

WMS — 창고

랙·존·층 단위 위치 기반 재고 관리, 입출고 예약과 도크 배정, FIFO·FEFO·LIFO 출고 전략, 창고 레이아웃 시각화와 3D 로케이션 뷰, 재고 조정·실사.

TMS — 운송

운송 주문, 차량·기사 자동 배차, 다중 배송지 경로 최적화, GPS 실시간 추적, 드라이버 앱 전자서명(POD), 거리·중량·유류비 반영 운임 산출.

ATS — 선적검수

항만 선적 화물의 검수 체크리스트, 검수 결과와 불합격 처리, 선적 확인서 자동 발행, 검수자별 실적과 이력, 모바일 스캔 연동.

현장 모바일

입고 검수, 피킹, 출고, 선적 검수를 스마트폰·PDA에서 처리. 바코드·QR 스캔으로 위치와 화물을 확정합니다.

연계

관세청 전자문서, 선사·항공사 스케줄, 고객 ERP와 OpenAPI·EDI로 연계. NF1 공통 기반 위에서 Manager·PM과 같은 권한 체계를 씁니다.

창고를 3차원으로 봅니다

로케이션 마스터는 창고·구역·층별 랙을 3D로 그려 빈 칸·사용 중·예약·점검 상태를 색으로 보여 줍니다. 구역별 점유율과 SKU·빈 검색, 랙을 클릭하면 열리는 정면도(Elevation)로 셀 단위 상태까지 확인합니다.

  • 구역별 점유율과 가용 위치 실시간 집계
  • Top·Front·Side·3D 시점 전환, 랙 회전·스냅
  • 정면도에서 셀 단위 사용 상태 확인
