하나의 콘솔에서

Docker 컨테이너 배포 상태부터 DB 쿼리 분석, API 상태, 실시간 로그 스트림까지. 운영팀에 필요한 도구를 업무 시스템 안에 임베드된 콘솔로 제공합니다.

다섯 가지 운영 도구

배포 → 서버 → API → 로그 → 자동화. 장애가 났을 때 운영자가 따라가는 순서대로 도구가 이어집니다.

Docker 배포 대시보드

컨테이너 상태·업타임을 실시간으로 보고, GitHub Actions 배포 이력을 프런트·백엔드로 나눠 커밋별 성공·실패를 확인합니다. Job별 로그는 슬라이드 패널로 봅니다.

서버 · DB 쿼리 모니터링

CPU·메모리·디스크와 함께 10초 간격으로 쿼리를 수집합니다. 그래프에서 구간을 드래그하면 그 시점의 슬로우 쿼리 Top 10과 평균·표준편차·버퍼 히트율·임시 블록 지표를 바로 보여 줍니다.

API 매니저

모든 엔드포인트의 호출 현황과 응답시간을 추적하고 4xx·5xx 오류를 즉시 감지합니다. REST 원칙 준수와 JWT 인증 상태를 점검합니다.

Backsight 로그

서버 로그를 실시간 스트리밍하고 INFO·WARN·ERROR·DEBUG 레벨로 필터합니다. 에러 원인과 해결 방법을 AI 분석 패널에서 바로 묻습니다.

N8N 워크플로우 자동화

비주얼 워크플로우 빌더를 시스템에 임베드해 주문 접수 알림, 이상 감지 경보, 정기 보고서 발송을 코드 없이 구성합니다. Webhook·Slack·이메일·DB 연동, 스케줄 실행, 단일 로그인.

어디서나 같은 콘솔

클라우드와 온프레미스 어디에 설치해도 같은 콘솔입니다. NF1 권한 체계로 운영자·개발자·관리자 역할을 나눕니다.

장애 대응 흐름

알림이 오면 배포 대시보드에서 최근 변경을 확인하고, 서버 모니터링에서 문제 구간을 드래그해 슬로우 쿼리를 찾고, API 매니저에서 영향 받은 엔드포인트를 확인한 뒤, Backsight에서 에러 로그와 AI 분석으로 원인을 좁힙니다. 재발 방지 알림은 N8N 플로우로 등록합니다.

운영 콘솔을 직접 보시겠습니까

실제 운영 환경에서 Manager 콘솔을 시연해 드립니다.
