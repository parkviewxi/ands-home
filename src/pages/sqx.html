하나의 플랫폼으로

분석·설계·구현·운영·유지보수를 단일 플랫폼으로 통합한 오픈소스 기반 엔터프라이즈 플랫폼입니다. 공통 프레임워크 위에 운영 관리, 스키마 분석, 프로젝트 관리, 물류 업무 제품을 올려 구축 기간과 운영 비용을 함께 줄입니다.

프레임워크

NF1·NF2·NS2·VS1은 같은 공통 기반을 서로 다른 기술 스택으로 구현한 풀스택 프레임워크입니다. 고객사의 기존 인프라, 운영 인력의 기술, 보안 정책에 맞춰 선택합니다.

NF1

Next.js + FastAPI

가장 많은 제품이 올라가 있는 기준 프레임워크. 멀티테넌트 공통 기반과 JWT 인증, 채번·공통코드를 제공합니다.

  • Next.js
  • React
  • FastAPI

NF1 자세히

NF2

Next.js + FastAPI, 2세대

NF1과 같은 공통 기반을 최신 Next.js·React 버전으로 재구성한 프레임워크.

  • Next.js
  • React
  • FastAPI

NS2

Next.js + Spring Boot

자바 WAS를 표준으로 쓰는 공공·금융 인프라에 맞춘 구성. 프런트와 백엔드를 분리 운영합니다.

  • Next.js
  • Spring Boot
  • Java

VS1

Vue + Spring Boot

Vue 프런트 환경을 운영하는 고객사에 맞춘 구성.

  • Vue
  • Spring Boot

프레임워크별 기술 스택 조합은 대표적인 구성이며, 고객 환경에 따라 프런트·백엔드 조합을 바꿔 구축합니다.

제품

아래 화면은 모두 실제 운영 중인 제품 화면입니다.

SQX Manager

Docker 컨테이너 배포 상태, 서버·DB 쿼리 모니터링, API 응답 추적, 실시간 로그 스트림, N8N 워크플로우 자동화를 하나의 임베디드 콘솔에서 제공합니다.

  • 컨테이너·CI/CD 배포 이력 실시간 확인
  • 슬로우 쿼리 Top 10, API 4xx/5xx 즉시 감지
  • AI 로그 원인 분석

Manager 자세히

SQX ERD

DB 전체 테이블을 자동 배치하고 FK 관계를 시각화하는 인터랙티브 ERD 뷰어. 선택한 테이블을 맥락으로 AI에게 관계·설계·쿼리 최적화를 묻고, 스냅샷으로 스키마 변경 이력을 추적합니다.

  • FK 경로 탐색과 JOIN 쿼리 자동 생성
  • 스냅샷 비교, DDL 확인

ERD 자세히

SQX PM

요구사항·응용기능·프로그램·산출물·QA·변경관리를 잇는 소프트웨어 프로젝트 관리(SPM)와, 변경요청·문제관리·SLA·지식베이스를 갖춘 ITSM을 한 플랫폼에서 제공합니다.

  • 요구사항 추적 매트릭스와 단계별 산출물 심사
  • RFC 승인 흐름, SLA 정책과 준수율 대시보드

PM 자세히

SQX Logistics

포워딩(FMS)·창고(WMS)·운송(TMS)·선적검수(ATS)를 하나로 묶은 통합 물류 플랫폼. 창고 로케이션을 3차원으로 보여 주는 3D 뷰로 재고 위치와 점유율을 한눈에 확인합니다.

  • BL·컨테이너·운임, 위치 기반 재고, 배차·추적, 선적 검수
  • 바코드·QR 스캔, 모바일 현장 처리
